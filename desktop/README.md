# MOEX Live Screener Pro — Electron Desktop Application

Десктопное приложение для скринера технических индикаторов и сигналов акций MOEX (Т-Инвестиции PRO), разработанное на связке **Electron** + **Vite**.

---

## Возможности

- **Безрамочный терминальный интерфейс (Frameless):** кастомный Title Bar с поддержкой перемещения окна за шапку (`-webkit-app-region: drag`), кнопками сворачивания, разворачивания, полноэкранного режима (Full Screen / Kiosk) и закрытия.
- **Работа в системном трее (System Tray):** при нажатии кнопки закрытия окно не завершает процесс, а сворачивается в трей для непрерывного мониторинга. В трее доступно контекстное меню (восстановление, статус бэкенда, выход).
- **Нативные всплывающие уведомления Windows:** автоматические алерты при формировании сильных сигналов на покупку/продажу (RSI / Nadaraya-Watson / CCI / STCH).
- **Автоматическое управление бэкендом:** Electron при запуске проверяет доступность локального аналитического бэкенда (`backend/`) на порту 8080. Если он не запущен, Electron запускает его в фоновом режиме, а при выходе из приложения корректно останавливает дочерний процесс.
- **Двойной режим данных:** прямое подключение к живому WebSocket-потоку `ws://127.0.0.1:8080/stream` с автоматическим переключением на встроенный генератор симуляции котировок, если бэкенд оффлайн или не настроен токен API.
- **Полная функциональность оригинального шаблона:**
  - Переключение таймфреймов (1м, 5м, 15м, 1ч, 4ч, Д).
  - Смена тикера на полное наименование компании при наведении курсора.
  - Фильтры по активам (Все акции, Голубые фишки, Высокий объем, Активные сигналы).
  - Режимы стратегий (RSI+NW базовый, строгий консенсус, только NW, только RSI).
  - Включение/отключение осцилляторов CCI и STCH.
  - Модальное окно настроек: слайдер среднего объема за X дней (5–60 дней) и порогов индикаторов.
  - Темы оформления: Night, Light, High Contrast, Condensed.

## Быстрый запуск

### 1. Обычный запуск приложения
Запустите файл в корне репозитория:
```bat
start-desktop.bat
```
*(или в терминале: `cd desktop && npm start`)*

### 2. Запуск в режиме разработки (HMR / горячая перезагрузка)
```bat
start-desktop-dev.bat
```
*(или в терминале: `cd desktop && npm run dev`)*

## Структура проекта

```
desktop/
├── dist/                     # Скомпилированный статический фронтенд (Vite)
├── scripts/
│   └── dev.js                # Скрипт синхронного запуска Vite + Electron
├── src/
│   ├── main/
│   │   ├── main.js           # Главный процесс Electron (окно, IPC, жизненный цикл)
│   │   ├── backend-manager.js # Автозапуск и контроль локального бэкенда (порт 8080)
│   │   └── tray.js           # Меню и иконка в системном трее
│   ├── preload/
│   │   └── preload.js        # Безопасный IPC-мост (ContextBridge)
│   └── renderer/
│       ├── index.html        # Шаблон скринера с десктопными элементами
│       ├── js/
│       │   ├── app.js        # Движок скринера, расчет сигналов, WebSocket
│       │   └── desktop-controls.js # Обработчики кнопок окна и уведомлений
│       └── styles/
│           └── main.css      # Стилизация терминала и дизайн-токены
├── package.json
└── vite.config.mjs
```
